Вышло обновление бота

⚠️ Важно: бот перешёл на новую модель данных — старая привязка к группе
сброшена, нужно подписаться заново (инструкция ниже).

Новые возможности:

🏫 Теперь бот поддерживает много институтов и групп, а не только одну
группу.

🔍 /start — удобный выбор института и группы с поиском по названию.

📋 /menu — главное меню с кнопками: расписание, подписка, староста,
заявки — команды помнить не нужно.

👤 Роль старосты: выборы (/starosta, /votes), управление группой
(закрыть/открыть вступление, рассылка своей группе).

🔁 /change_group — заявка на переход в другую группу.

👥 /classmates — список одногруппников.

💬 /report и /faq — обратная связь и справка по командам.

🖼️ Точнее кроп скриншота расписания — только нужная колонка.

---

Как снова подписаться на рассылку:

1. Откройте чат с ботом в Telegram.
2. Отправьте /start.
3. Выберите институт.
4. Выберите группу.
5. Готово ✅ — рассылка и уведомления об изменениях возобновятся
   автоматически.
