# Список одногруппников — дизайн

Дата: 2026-10-08

Под-проект 3 из 5 (мультигрупповость → старосты → **соцслой** →
привилегии старосты → UI-меню). Зависит от под-проекта 1 (`members`
хранит `telegram_username`/`display_name`, `storage.list_group_members`)
и от под-проекта 2 (`groups.starosta_chat_id` для пометки старосты в
списке). Это самодостаточная, небольшая фича — одна новая команда без
изменений схемы.

## Команда `/classmates`

- Доступна **любому** пользователю с закреплённой группой
  (`storage.get_member`), независимо от `subscribed` — список не
  привязан к рассылке. Без закреплённой группы — подсказка выбрать
  группу через `/start`.
- Источник данных — `storage.list_group_members(conn, group_id,
  subscribed_only=False)` плюс профильные поля из `members`
  (`telegram_username`, `display_name`), уже заполняемые под-проектом 1
  (включая опортунистическое самовосстановление профиля на каждом
  взаимодействии — так что список стабильно не пустой для активных
  участников).

## Формат одной строки

Приоритет отображения — **и** имя, **и** `@username`, если оба
доступны, а не один в ущерб другому:

- `display_name` и `telegram_username` оба есть → `Имя Фамилия (@username)`.
- только `display_name` → `Имя Фамилия`.
- только `telegram_username` → `@username`.
- ни того, ни другого → `Неизвестный`.

Староста группы (`groups.starosta_chat_id`) помечается значком перед
строкой (👑), чтобы было видно, к кому обращаться — к моменту вызова
команды старосты может и не быть назначено, тогда значок просто не
ставится ни у кого. Если в группе есть староста, под списком выводится
строка-легенда «👑 — староста группы»; если старосты нет, легенда не
показывается (значка в списке и так не будет).

Список сортируется по итоговой отображаемой строке (алфавитно) — так
порядок стабилен между вызовами и не зависит от порядка `joined_at`.

## Форматирование — общая функция

Строка одного участника форматируется чистой функцией
`format_member_line(member: MemberRow, is_starosta: bool) -> str`,
без I/O — легко покрывается юнит-тестами на все четыре комбинации
имя/username и оба варианта пометки старосты.

## Тестирование

- `format_member_line` — 4 юнит-теста на комбинации
  display_name/username (оба / только имя / только username / ничего),
  плюс 2 теста на пометку старосты (есть/нет).
- Юнит-тест команды: группа с 3 участниками (один — староста) →
  ожидаемый порядок строк, значок у правильного человека, и наличие
  строки-легенды «👑 — староста группы» в конце сообщения.
- Юнит-тест команды для группы без назначенного старосты → ни у кого
  нет значка и легенда не выводится.
- Тест на пользователя без закреплённой группы → подсказка про `/start`,
  без обращения к `list_group_members`.

## Вне охвата этого под-проекта

- Исключение участников, закрытая/открытая группа, `/notify`
  (под-проект 4) — там же появится кнопка «Исключить» рядом с каждым
  именем в аналогичном списке для старосты; эта команда (`/classmates`)
  останется read-only версией для всех.
- Редизайн UI в инлайн-меню (под-проект 5).
